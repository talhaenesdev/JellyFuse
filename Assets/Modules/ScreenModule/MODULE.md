# ScreenModule

## Purpose
The project's screen host: it builds the screen manager the other modules register their screens with.

## Concepts
screen root, screen manager, screen host, layers, Core

Update: never

## Safe area
FlowIoC's ScreenSafeArea fits the safe-area layers once, in Awake. In the Editor that first frame
reports the Simulator or Game window's own size against the device's safe area, so the layers come
out larger than the screen and every screen shifts up and right. SafeAreaRefresh, beside it on the
ScreenManager in ScreenRoot, fits them again whenever Screen size or safe area changes, clamped to
the screen. On a device it changes nothing.
