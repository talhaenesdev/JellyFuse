# Analytics

## Purpose
Sends game events to Unity Analytics - level started, won, lost - so the dashboard shows where players get stuck and where they leave. Game-agnostic: a caller names the event and hands its parameters.

## Concepts
analytics, events, telemetry, funnel, Unity Analytics, UGS, IAnalyticsService

## Decisions
- **Collection starts as the game opens**, initialising Unity Services itself if the account module has not yet. Events recorded before that are queued by the SDK, not lost.
- **Editor events are not sent.** Play in the Editor logs the event on the module's channel instead, so testing a flow does not fill the dashboard.

## Known gaps
- Unity Analytics drops a custom event that is not defined in the dashboard's Event Manager. `level_start`, `level_complete` and `level_fail`, each with the parameters their callers send, have to be created there once.
- No consent screen. Collection starts unasked, which is fine for Turkey; a release in the EU needs a consent prompt before `StartDataCollection`.
