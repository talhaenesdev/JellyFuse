# ProfileSelectionScreen

## Purpose
Edits the player's display name, avatar and profile frame from configurable catalogues.

## Concepts
profile editor, player name, avatar picker, frame picker, profile icon grid

## Presentation
The pooled ProfileSelectionScreen keeps the MainScreen cosmic visual family: a navy glass dialog,
gold title and save action, cyan active tab, large live avatar/frame preview and a three-column
catalogue grid. The name is edited through TMP_InputField (16 character limit); changing avatar or
frame updates the preview immediately, while Save sends the complete draft through SaveRequested.
