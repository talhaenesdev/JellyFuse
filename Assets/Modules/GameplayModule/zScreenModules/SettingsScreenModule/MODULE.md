# SettingsScreen

## Purpose
The settings screen opened from the main menu's settings button. Shows the player's notification, sound, music and haptic preferences.

## Concepts
settings, options, notification, sound, music, haptics, settings button

## How it works
- The HUD's settings button (GameplayScreen Outgoing.SettingsClicked) opens it through
  SettingsConnectorSubContext, on layer 2 over the gameplay screen, which stays open underneath.
- OpenSettingsScreenCommand fills the four toggles. Notification, sound and music preferences are
  owned by SettingsModel; haptics is read and changed through IHapticService.
- Each toggle dispatches the same internal ToggleOption signal. ToggleSettingOptionCommand decides
  which setting changes, persists it, and announces OptionChanged so the View swaps its atlas sprite.
- The View uses authored Art sprites from Atlas_Placeholder and scales the complete dialog uniformly
  inside the device safe area.
- Close decides nothing, so the Mediator hides the screen itself.
- Language names are shown in their own language (English, Türkçe) and are not translated.
