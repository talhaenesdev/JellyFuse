# CloudSave

## Purpose
Keeps small key/value records on the signed-in player's Unity Gaming Services account and reads them back. Game-agnostic: it answers the keys and strings it is handed and knows no game data.

## Concepts
cloud save, cloud storage, UGS Cloud Save, remote save, player data, ICloudSaveService

## Decisions
- **String values only.** A caller serialises its own data, so the service knows no game type and
  the record in the dashboard reads as the text that was sent.
- **Signed out answers like offline.** `SaveAsync` returns false and `LoadAsync` null; `LoadAsync`
  answers an empty dictionary - not null - for a player who never saved, so a caller can tell
  "nothing there" from "could not ask".
