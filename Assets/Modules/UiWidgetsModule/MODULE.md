# UiWidgets

## Purpose
Reusable UI pieces any screen can put in its prefab - drawing components with no game rules and no signals. MirroredCapBackground draws a text background from a left cap and a middle piece, mirroring the cap for the right end and sizing itself to the text. TextAnimator animates a TextMeshPro text with DOTween from a CD_TextAnimation preset.

## Text animation
- Add **TextAnimator** next to any TMP text, drag a **CD_TextAnimation** preset onto it, and tick when it plays: *Play On Enable* (each time it is shown) and/or *Play On Text Change* (each time its text changes - a score, a counter).
- Presets live in `Scriptables/TextAnimations/` (Pop, Punch, FadeIn, SlideUp, Typewriter, Shake, Pulse, Wave, CountUp). A preset is a list of effects that play together; make new ones with *Create > UI Widgets > Text Animation*.
- Effects: Pop, Punch, FadeIn, SlideIn, Typewriter, Shake, Pulse (Loop to repeat), Wave (always repeats), CountUp (the number in the text counts from the one shown before to the new one).
- From code: `Play()`, `Play(preset)`, `SetText(text)` (sets the text and plays, counting from the number before), `Stop()` (puts the text back; a count stopped half way shows its end).
- It uses DOTween's core API only (`DOTween.To`, `DOScale`), so it needs no DOTween module assembly.
