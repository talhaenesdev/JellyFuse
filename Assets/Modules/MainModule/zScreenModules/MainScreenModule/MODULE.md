# MainScreenModule

## Purpose
The game's main menu: coins, settings, Play, and the navigation bar with Home.

## Concepts
main menu, title screen, play button

## Layout
Authored in Prefabs/MainScreen - move, resize and recolour there. Objects are named Type_What: Btn_ a button, Txt_ a text, Img_ an image, Pnl_ a container or card.
- Img_Background uses Art/Textures/Main_Menu/T_bg_MainMenu.jpeg behind everything; Pnl_Layout is
  the 760-unit-wide column, scaled to the screen.
- The shared top HUD uses separate sunny-theme currency and lives capsules plus a round settings
  button; all three stay visible on both pages.
- Pnl_HomePage contains the ornate avatar card, purple-gold level ribbon and decorated Btn_Play.
- Pnl_ShopPage contains the SHOP header, daily offer and the four visual product cards. Purchase
  buttons are presentation-only until the game's offer catalogue and store backend are defined.
- Pnl_NavBar along the bottom uses its own three-slot illustrated capsule with Btn_Nav_Shop,
  Btn_Home and Btn_Nav_Events. Img_NavSelector slides behind the tab picked (MainScreenView's
  Selector Time); the screen opens on Home. Events is index 2 and opens the separate EventsScreen;
  it is not a page inside this prefab. Tab labels are keyed main.nav.<index> (Home: main.home).
- Texts: Txt_Play and Txt_Home are keyed (main.play, main.home in CD_GameplayTexts); the English in
  the prefab is the fallback. OpenMainScreenCommand hands the screen ILocalizationService.Get.
- Btn_Settings opens the settings screen (SettingsConnectorSubContext); HomeClicked is announced
  and not wired yet. ApplyCoins shows a count; nothing sends one yet.
- Shop is index 0 and Home is index 1. MainScreenView switches those two authored page panels while
  keeping the shared HUD and navigation alive on the same pooled screen.
- Navigation uses DOTween: Selector Time moves Img_NavSelector without changing its authored size;
  Selected Tab Scale and Tab Scale Time control the selected tab image. Home is index 1 and is
  selected whenever the pooled screen opens.
- CD_MainScreenTheme controls the Play, utility, shop purchase, navigation and selector colours;
  MainScreenView reapplies it whenever the pooled screen opens and whenever a navigation tab changes.
